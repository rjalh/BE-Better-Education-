# Better Education — іске қосылатын full-stack MVP

**Бұл жеке HTML-макет емес.** Сервер — FastAPI, дерекқор — SQLite (немесе PostgreSQL), интерфейс — HTML/CSS/JavaScript. Браузерде басылған батырмалар нақты серверлік API-ге сұраныс жібереді. Тестілеу нәтижелері, бағалар, тапсырмалар, аккаунттар және марапаттар дерекқорда сақталады.

## 1. Ең оңай іске қосу (Mac / VS Code)

1. Архивті толық аш.
2. VS Code арқылы **BetterEducation_Launch** папкасын аш.
3. **Terminal → New Terminal** ашып, мына командаларды жаз:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

4. Браузерден **http://localhost:8000** аш.

Немесе Mac-та `START_MAC.command` файлын іске қос; Windows-та `START_WINDOWS.bat`.

**Маңызды:** `index.html` файлын екі рет шертіп ашпа. Бұл толыққанды серверлік қосымша. Ол Python сервері іске қосылғанда жұмыс істейді.

## 2. Docker арқылы іске қосу

Docker Desktop орнатылған болса, папка ішінен:

```bash
docker compose up --build
```

Сайт: **http://localhost:8000**. SQLite деректері `be_data` Docker volume ішінде қалады. Тоқтату үшін `Ctrl+C`. `docker compose down -v` барлық деректі өшіреді — абай бол.

## 4. Нақты жұмыс істейтін функциялар

**Оқушы:** пәндерді көру; сабақ оқу және «пройден» белгілеу; 16 дайын тест (80 сұрақ), жауапты сервермен тексеру, түсіндіру, тест нәтижесін сақтау, қайта тапсыру; тапсырманы мәтінмен тапсыру; журналдағы бағаларды көру; BEcoin/Stars есептеу және дизайн тақырыптарын сатып алу; кесте және хабарламалар; профиль, тіл және пароль параметрлері.

**Мұғалім:** тағайындалған сыныптар бойынша журналға баға қою; тапсырма жариялау; келіп түскен жұмысты тексеріп, кері байланыс беру; **жаңа сабақ құру; өз тестін 1–30 сұрақпен құру**; кестеге іс-шара қосу; сыныпқа хабарлама жіберу.

**Ата-ана:** тек әкімшілік тіркеген баланың бағаларын, үлгерімін, оқу барысын, хабарламаларын көреді.

**Әкімшілік:** жаңа оқушы/мұғалім/ата-ана аккаунтын құру; сынып, пән құру және мұғалімді тағайындау; ата-ананы оқушымен байланыстыру; мектеп атын өзгерту; журнал мен кестені басқару.

**Bebeshka:** оқу көмекшісі. `OPENAI_API_KEY` жоқ кезде сұраққа тақырыптық **офлайн анықтамалық** жауап береді, генеративті AI деп көрсетілмейді. API кілті орнатылғанда сыртқы AI сұрауы серверден жіберіледі (модель қолдауы мен API тарифіне байланысты). Оқушылардың журнал жазбалары модельге берілмейді.

## 5. Адаптивтілік / смартфон

Сайт құрылымы desktop, tablet және smartphone ендеріне бейімделген. Телефонда төменгі навигация көрсетіледі. Жергілікті Wi-Fi ішіндегі басқа құрылғыдан ашу үшін компьютердің жергілікті IP мекенжайын тауып, телефоннан `http://КОМПЬЮТЕР_IP:8000` аш; екі құрылғы бір желіде болуы керек, компьютердің firewall-ы рұқсат беруі тиіс.

**Қоғамдық интернетке жариялау** үшін серверлік хостинг, HTTPS және домен қажет. Біз бұл архивтен сенің аккаунтыңдағы хостингке өз бетімізбен орналастырған жоқпыз.

## 6. Демо емес, жеке мектепті бастау

`.env.example` үлгісін алып, ортаның айнымалыларын орнат:

```bash
export BE_DEMO_MODE=0
export SESSION_SECRET="$(python3 -c 'import secrets;print(secrets.token_urlsafe(48))')"
export ADMIN_EMAIL="admin@your-school.kz"
export ADMIN_PASSWORD="LONG_UNIQUE_PASSWORD_CHANGE_ME"
export COOKIE_SECURE=0 # local HTTP only; HTTPS on public deployment = 1
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Осыдан кейін бірінші іске қосуда бір мектеп, `8A` сыныбы және әкімші аккаунты құрылады. Келесі қадамдар: әкімші болып кіру → мұғалім құру → сынып/пән құру → оқушылар қосу → мұғалім сабақ/тест құру → оқушылар кіреді.

Жаңа бос дерекқор қолдану маңызды: бұрын демо режимде жасалған SQLite базасында демо деректер қала береді. Демо базасын жеке жаңа база ретінде пайдаланба.

**Маңызды:** оқушыларды жаппай тіркеп, қоғамдық өнім ретінде жарияламас бұрын security review, rate limiting үшін ортақ store, парольді қалпына келтіру, әкімшілік аудит, деректерді сақтау/өшіру саясаты, backup, миграциялар, балалардың деректеріне қатысты құқықтық талаптар және real-device QA қажет. Бұл жұмыс істейтін **pilot MVP**, бірақ толық өндірістік қауіпсіздік сертификатталған жүйе емес.

## 7. PostgreSQL

SQLAlchemy `DATABASE_URL` арқылы PostgreSQL қолдана алады. `requirements.txt` құрамында psycopg драйвері бар. Мысал:

```bash
export DATABASE_URL='postgresql+psycopg://USER:PASSWORD@HOST:5432/DATABASE'
```

Өндірісте PostgreSQL, басқарылатын сақтық көшірмелер, құпия environment variables, HTTPS reverse proxy қолдан. SQLite бір серверлік пилотқа ғана қолайлы.

## 8. Автоматты тесттер

```bash
python -m pip install pytest
python -m pytest -q tests/test_product.py
node --check app/static/app.js
```

Тексеру: рөлдік қолжетімділік, екі мектептің оқшаулануы, сұрақтардың жауаптарының жасырылуы, балл есептеу, қайта тапсыру, бағалардың өзгеруі, хабарламалар, сатып алу, сабақ/тест құру, оқушы мен ата-ананы қосу, production bootstrap.

Қазіргі жинақта **18 API integration тесті өтті**. Осы орында браузерлік Chromium навигациясы әкімшілік шектеуге байланысты орындалмады; браузердегі барлық шерту мен барлық құрылғыдағы визуалды QA өтті деп айтпаймыз.

## 9. Файлдар

- `app/main.py` — API, backend және рөлдік рұқсаттар.
- `app/models.py` — дерекқор кестелері.
- `app/seed.py`, `app/content.py` — демо-мәліметтер және 16 тест.
- `app/security.py` — пароль хэштеуі және cookie session.
- `app/static/index.html` — негізгі HTML қабықшасы.
- `app/static/styles.css` — адаптивті дизайн.
- `app/static/app.js` — нақты API-лермен жұмыс істейтін фронтенд логикасы.
- `Dockerfile`, `compose.yaml` — контейнермен орнату.
- `tests/test_product.py` — тексеру сценарийлері.
